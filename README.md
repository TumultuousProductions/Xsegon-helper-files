# Xsegon helper files

**This is not the Xsegon program, and nothing here is for you to download.**

To get Xsegon, go to
**[Xsegon's download page](https://github.com/TumultuousProductions/Xsegon/releases/latest)**
and take the file marked **Windows install** or **Linux install**.

## What this is

Xsegon's own download page carries only the files people need, so nobody
takes the wrong one. Everything else that belongs with Xsegon lives here
instead, each on a release of its own:

- **Files Xsegon fetches by itself**, such as its update files, which a copy
  downloads when you press Update now.
- **Source code that other projects' licences ask Xsegon to offer**, for the
  parts of those projects that come inside Xsegon.

Xsegon's update files move here from Xsegon 0.18.

## The rule

- **Files for people** (the Windows and Linux installs) go on
  [Xsegon's release page](https://github.com/TumultuousProductions/Xsegon/releases).
- **Files for Xsegon itself, or kept because a licence asks**, go here.
- Nothing here is ever a file a person needs to download.
